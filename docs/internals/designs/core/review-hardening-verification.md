## Reproduction and artifacts

Run `python3 scripts/validate_review_evidence.py` to validate the two 30-row ID sets,
commit object existence, current RH regression class/method names and local core
documentation link targets. It does not claim that a named test passed or that a
historical commit is sufficient to prove an invariant without review.

Run `./scripts/adkw check-backlog`, `./gradlew --no-daemon validateBacklogIndex` and
`git diff --check` for backlog/frontmatter/index consistency and whitespace.

`user_notif_liveness`, `supervisor_installation`, `profiler_evidence_flow`,
`daemon_startup`, `portal_lifecycle`, `portal_codegen`, and `vulnerable_web_lifecycle`.

regenerates the compiled enforcer/profiler class diagrams. Generation is opt-in and
does not dirty ordinary builds.

JUnit XML and HTML are under each module's `build/test-results/<task>` and
`build/reports/tests/<task>`; JaCoCo reports are under `build/reports/jacoco/`.

`build/reports/refactorFirst/refactor-first-report.html` and requires an explicit
`./gradlew refactorFirstReport` invocation. No report was regenerated by these gates.

## Remaining capability limits

- Accept with peer-address output remains explicitly unsupported and fail-closed;
  [the identity-bound write capability](../../backlog/issue-20260910-171157-430-restore-accept-peer-address-writes-through-identit.md)
  is open. Address-less accept has native integration evidence.
- SIGKILL cannot guarantee immediate reaping of an uninterruptible kernel task.
  Unreaped helpers retain occupied capacity and cleanup failure is visible.
- Tracee mapping validation is bounded evidence, not an atomic snapshot against
  concurrent `mmap`/`mprotect`; documented secure-exec and filesystem race limits remain.
- Isolated-test descendant cleanup covers observed process handles; a child that
  forks and reparents entirely between observations may escape discovery.
- Docker compose syntax/contracts and loopback Spring scenarios were verified by
  the web package; actual Docker services were not launched as part of that evidence.

Watchdog review guarantee: no watchdog thread interrupts arbitrary JVM work. The
reactor owns the monotonic deadline, claims at most one terminal reply, emits
redacted deadline-near metrics, and disposes late results. A stalled reactor is a
process-health incident requiring external supervision; metrics do not extend or
silently bypass the security deadline.
