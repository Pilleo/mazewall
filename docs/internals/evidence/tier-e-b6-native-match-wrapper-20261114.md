## Wrapper contract and scope

The wrapper validates output pointer/alignment/size first, then checked declared input/output address ranges and overlap before any input read or output write. It copies well-formed requests to aligned local storage, strictly validates all wrapper and embedded request fields, calls the hidden matcher once only for well-formed input, and writes a complete fixed status result. It returns only Match, Unavailable, or Malformed; it never dereferences or outputs `path_bits`. Output/range failures and overlap do not write; malformed input with safe output returns initialized Malformed. Zero process cookie/start ticks and tgid/tid outside `1..INT32_MAX` are malformed; nonzero high-bit cookie/start values are valid format. A C++ exception barrier exists but its catch branch was not forced in tests and does not make arbitrary pointers/process faults/`noexcept` termination safe.
